All processing stays in your browser. No dependencies, pretrained weights, internet calls, or backpropagation. Webcam permission may require localhost / HTTPS rather than opening file://.

Self-repair starts with shape-only matching. One 84-frame cycle calibrates the prototype bank; thereafter familiar disagreement can open the motion tap, while unfamiliar surprise can write new transitions. Freeze writes for a fair transfer test.

The exact spatial identity is x = core + middle + fast. The prediction uses three spatially shared patch heads (3×3 core, 5×5 residues). The collision image sums component-wise recalled transition dispersion; it is an uncertainty diagnostic, not a calibrated causal probability. Free-run may collapse or drift. A moving cursor impulse is not a proof of independent autonomous physics. See the repo README for the deterministic benchmark and limitations.
